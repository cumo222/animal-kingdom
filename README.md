## ✨ 游戏特色

- **羊皮纸美术版**（v2.1.0）：借鉴《种呱得呱》《圆圆滚滚大农场》《农庄牌》的视觉共性，全局升级为暖色羊皮纸卡牌质感——纸纹背景、深棕描边、烫金 Logo 与卷轴军令横幅、便签式关卡目标、圆点阶段步骤条、竖版军队卡（草地球场插画 + 星级 SVG + 稀有度金/蓝边框）、草地花瓣战场格，铁牛盾卫/白羊医官角色插画全面重绘，320px 窄屏单独适配
- **三合一升星**：同名同星 3 只合成升一级（1 星 → 2 星 → 3 星），每次升星技能同步升级
- **同名叠放**：同星单位可叠放强化，每次 +1 攻击 +1 生命，无上限
- **双货币经济**：金币（招募/买卡/买地/道具）+ 粮食（军队每回合维持费）
- **五段回合流程**：① 回合开始（被动/维持费）→ ② 合成与部署 → ③ 商店窗口 → ④ 敌人推进攻击 → ⑤ 回合结算
- **行动点系统**（v2.0.0）：每回合操作阶段 3 点，部署/叠放/三合一各耗 1 点，让每一步操作都有决策张力
- **关卡目标 KPI**（v2.0.0）：每关随机 3 个目标（限时胜利/王都血量/三合一次数等），达成奖励金币，全达成送卡包
- **冒险刮刮乐**（v2.0.0）：第 6 关事件小游戏，3×3 刮奖赢取金币/粮食/军队/2 星大奖
- **军令叙事**（v2.0.0）：普通/商店/精英/事件/Boss 五类军令横幅 + 部署/升星/叠放动效
- **军队阵容**：铁牛盾卫（前线盾卫）、白羊医官（支援牧师），各 3 星技能与天赋
- **章节推进**：第 1 章「草原兽潮」8 关完整可玩，含精英关、事件关与 Boss 草原狼王；第 2-4 章与无限模式已按设计框架呈现（占位）
- **全内联 SVG 视觉**：天蓝/奶油/草绿/暖白治愈系配色，无任何外部图片与资源

## 🕹️ 操作说明

| 操作 | 说明 |
|---|---|
| 招募卡包 | 在部队面板购买卡包，五选二加入队伍 |
| 三合一合成 | 把 3 只同名同星单位拖到同一格，自动升星 |
| 同名叠放 | 把同星单位放到已有单位格，+1/+1 强化 |
| 部署军队 | 手牌选择军队 → 点击空土地部署（消耗 1 行动点） |
| 商店窗口 | 每回合进入商店：军队三选一、粮食补给、刷新 |
| 战斗结算 | 敌人推进攻击，优先打前线 → 中排 → 后勤，守住王都即可获胜 |

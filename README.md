# 动物王国 · Animal Kingdom

国家战争防御题材的可爱动物军队 **肉鸽构筑 + 合成升星** 游戏 —— 首页主菜单演示（单文件 HTML）。

## 运行方式

直接用浏览器打开 `index.html` 即可，无需安装依赖、无需联网（页面全部视觉为内联 SVG 矢量插画）。

## 页面内容

- 入场加载画面（引导语「正在加载插件与技能」）
- 主菜单：开始游戏 / 军队图鉴 / 关卡章节 / 商店 / 设置
- 军队图鉴内置已确认设计的「铁牛盾卫」「白羊医官」完整三阶卡牌
- 章节选择：第 1 章草原兽潮（进行中）→ 第 2 章沙漠劫掠 → 第 3 章沼泽瘟疫 → 第 4 章冰原亡灵 + 无限模式
- 响应式：320px ~ 2560px 均可正常显示（手机横屏优先）
